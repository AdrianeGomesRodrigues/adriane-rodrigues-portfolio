# Adriane Rodrigues Portfolio

Act as a Principal UI/UX Designer crafting a hyper-minimalist, editorial portfolio site for Adriane Rodrigues. 

Design Inspiration: Minimalist Scandinavian & Editorial portfolios (like pavlosanchez.com and kester.work). High contrast, extreme restraint, no corporate clutter, zero buzzwords.

CRITICAL DESIGN SYSTEM RULES (STRICT OVERRIDES):

1. TYPOGRAPHY & FONTS:

   - Import and use 'Plus Jakarta Sans' (or 'Instrument Sans') from Google Fonts for all body copy and headings.

   - DO NOT use default system fonts (Arial, Calibri, Times).

   - Headings: Bold, clean, tight tracking (letter-spacing: -0.02em).

   - Body Text: Medium/Regular weight, generous line-height (1.6 to 1.75) for effortless readability.

2. AUTUMN COLOR PALETTE (DARK EDITORIAL):

   - Background: Deep Warm Charcoal / Dark Earth (#141312)

   - Secondary Panels/Hover Card Backgrounds: #1D1B1A (very subtle contrast)

   - Primary Text: Off-white / Warm Sand (#EFECE6)

   - Secondary Text / Meta Labels: Muted Warm Slate (#9E968D)

   - Accent Color: Terracotta / Burnt Sienna (#C85A32) - use strictly for links, subtle hover glows, or section numbers.

   - Borders & Dividers: Muted Warm Border (#2A2725) - thin 1px lines only.

3. LAYOUT & SPACING:

   - Max container width: 840px (centered single-column layout, giving it an essay/editorial magazine feel).

   - Generous vertical padding between sections (80px - 100px).

   - No flashy 3D cards, no corporate stat widgets, no rounded badge clouds.

CONTENT & STRUCTURE:

1. HEADER & HERO (Warm, Direct, Human):
